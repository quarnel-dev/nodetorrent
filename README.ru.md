# NodeTorrent

[Читать на английском](README.md) | Русский

![NodeTorrent CLI Demo](assets/demo.gif)

Лёгкий BitTorrent-клиент для командной строки с минимумом зависимостей, написанный с нуля на Node.js и TypeScript.

NodeTorrent создан, чтобы продемонстрировать низкоуровневую peer-to-peer работу с сетью, разбор бинарных протоколов поверх TCP и UDP, декодирование Bencode и асинхронный ввод-вывод на диск.

Это ранняя версия проекта (`v0.1.0`). Сейчас основной фокус — правильная реализация базового пути загрузки: разбор `.torrent`-файлов, обращение к HTTP/HTTPS и UDP-трекерам, подключение к пирам, обмен сообщениями wire-протокола и запись проверенных кусков на диск. Раздача, DHT, magnet-ссылки, PEX и шифрование пока не реализованы.

Цель проекта — не заменить зрелые клиенты вроде qBittorrent или Transmission, а быть читаемым примером того, как BitTorrent работает изнутри. Большая часть протокола — трекеры, соединения с пирами, wire-сообщения, проверка кусков — реализована с нуля; на стороннюю библиотеку опирается только декодирование Bencode.

В планах на будущие версии — раздача, DHT, magnet-ссылки, PEX и шифрование протокола, полный рефакторинг архитектуры проекта и сборка отдельного `.exe` через Node.js SEA (Single Executable Applications), чтобы CLI можно было запускать без установки Node.js. Ничего из этого пока не обещано — это одиночный сайд-проект, и приоритеты могут меняться по мере развития ядра протокола.

## Возможности

- **Поддержка нескольких трекеров**: параллельный опрос HTTP, HTTPS и UDP-трекеров с поддержкой `announce-list`. Публичные fallback-трекеры используются, когда трекеры из торрента не отвечают.
- **Реализация wire-протокола**: собственный TCP-движок wire-протокола, обрабатывающий сообщения Handshake, Bitfield, Have, Request, Piece и Choke/Unchoke.
- **Оптимизации производительности**:
  - **Pipelining**: до `MAX_PIPELINE` (10) блоков в очереди запросов на каждого пира для максимальной пропускной способности.
  - **Endgame Mode**: когда остаётся ≤3 кусков, запросы дублируются нескольким пирам, чтобы не застрять на медленных.
- **Целостность и хранение**:
  - Проверка SHA-1 для всех загруженных кусков.
  - Поддержка однофайловых и многофайловых торрентов с точной записью по смещению.
- **Интерактивный CLI**: меню конфигурации и живая панель в терминале с прогрессом, числом пиров и скоростью передачи.

## Стек технологий

- **Среда выполнения**: Node.js (формат ES Module)
- **Язык**: TypeScript 7.0
- **Сеть**: `node:net` (TCP), `node:dgram` (UDP), `node:http` / `node:https`
- **Хранение**: `node:fs/promises`
- **Парсинг**: [`bencode`](https://www.npmjs.com/package/bencode) для декодирования `.torrent`
- **CLI**: [`consola`](https://www.npmjs.com/package/consola) для логов, [`gradient-string`](https://www.npmjs.com/package/gradient-string) для оформления терминала
- **Инструменты разработки**: `tsx` для прямого запуска TypeScript, `typescript` для проверки типов

## Архитектура

```text
src/
├── download/              Оркестрация загрузки
│   ├── downloader/        Пул пиров, очередь, FileManager, PieceAssembler
│   └── peer/              Wire-протокол: handshake, сообщения, работа с сокетом
├── torrent/               Загрузчик .torrent, парсер Bencode, вычисление infoHash
├── tracker/               HTTP/HTTPS и UDP-клиенты трекеров, разбор пиров
├── ui/                    CLI-меню, живая панель, отрисовка прогресса
├── events/                Глобальная шина событий для download/peer/UI
└── main.ts                Точка входа приложения
```

- Node.js >= 20
- npm или pnpm

```bash
git clone https://github.com/quarnel-dev/nodetorrent.git

cd nodetorrent

npm i

npm run dev
```
